# Heroteca

Diário de filmes, séries, desenhos e HQs de heróis, com o jogo diário Heroidle.

- `site/` é o que vai para o ar (o Netlify publica esta pasta).
- `fonte/` tem o código-fonte: `pagina.html`, `estilo.css` e `js/`.
- `ferramentas/montar.py fonte site/index.html` junta tudo em um arquivo.
- `ferramentas/gerar_catalogo.py site/catalogo.json` gera o catálogo.

O site no ar: https://heroteca.netlify.app
